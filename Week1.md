# Week 1 – Software Engineering Fundamentals

## Overview

Welcome to the Full-Stack Software Engineering Internship!

This week is focused on understanding how professional software teams build, plan, and deliver software. Before writing production code, you'll learn the tools, workflows, and engineering practices used throughout the internship.

By the end of this week, you should be comfortable working with Git, understanding Agile development, and setting up your development environment.

---

# Learning Objectives

By the end of this week, you should be able to:

- Understand the Software Development Life Cycle (SDLC)
- Explain Agile and Scrum methodologies
- Understand the software development workflow
- Use Git and GitHub for collaboration
- Create and review Pull Requests
- Understand HTTP fundamentals
- Understand REST APIs
- Set up and run the project locally
- Understand the Assessment Dashboard project
